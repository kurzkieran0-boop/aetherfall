# aetherfall
## The Last Lighthouse Keeper

A 90-second procedural animated short in a single HTML file — geometry, textures, sky, water, character, whale and score are all generated in code (three.js r128 + WebAudio, no assets, no keys).

- `the-last-lighthouse-keeper.html` — loads three.js r128 from a public CDN (≈165 KB).
- `the-last-lighthouse-keeper.offline.html` — same film with three.js inlined; works with no network at all.

Open either file in a browser, or serve the folder from any static host. Space = play/pause, ←/→ = seek, M = mute, F = fullscreen.

## Keeper Seven — Part 1: Sixty Seconds of Dark

An 87-second serial thriller built on the same engine: the lamp goes out, a real-time 60-second countdown starts, and a second keeper is already at the lever. Ends on a cliffhanger; Part 2 ("What the Light Is For") is planned, not built.

- `keeper-seven-part-1.html` — loads three.js r128 from a public CDN.
- `keeper-seven-part-1.offline.html` — three.js inlined; needs no network.
